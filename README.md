# Конструктор занять · фізика та астрономія

Сайт-конструктор, який допомагає викладачеві зібрати точний промпт для ШІ-асистента (Claude, ChatGPT, Gemini) на основі матеріалу, плану заняття та ключових формул.

## Розділи

| Сторінка | Що робить |
|---|---|
| `index.html` | Титулка в стилі папок — кожна папка веде на окрему сторінку |
| `presentation.html` | Промпт для презентації: кількість слайдів, формат (HTML / Canva / Marp / .pptx), нотатки доповідача, тест |
| `scenario.html` | Промпт для сценарію заняття: обсяг у сторінках, етапи з таймінгом, методи, репліки, диференціація, тест |
| `notes.html` | Промпт для конспекту учня: обсяг A4, формат, розв'язані приклади, «перевір себе», тест |
| `cards.html` | Промпт для цікавих питань-карток з відповідями: кількість, типи, експорт у CSV для Anki / JSON / HTML |
| `universal.html` | Один запит на повний комплект: презентація + сценарій + конспект + картки + тест |
| `library.html` | Бібліотека готових матеріалів — полички заповнюються зверху вниз |

**Спільна «Основа заняття»** (предмет, тема, клас, тривалість, матеріал, план, формули) зберігається в браузері й підставляється на всіх сторінках — заповнюєте один раз.

Кнопки під промптом: копіювати, відкрити одразу в Claude чи ChatGPT, завантажити `.txt`, очистити.

## Як додати матеріал у бібліотеку

1. Завантажте готовий файл у корінь репозиторію поруч з іншими (наприклад, `kepler.html`).
2. Відкрийте `materials.js` (на GitHub — значок олівця) і додайте запис у масив:

```js
window.MATERIALS = [
  {
    title: "Закони Кеплера",
    subject: "Астрономія",        // "Фізика" або "Астрономія"
    type: "Конспект",             // Презентація | Сценарій | Конспект | Картки | Комплект
    grade: "11 клас",
    url: "kepler.html",
    date: "2026-10-17"
  },
];
```

Книжки стають на полиці в порядку списку: спершу заповнюється верхня полиця, потім наступні.

## Публікація

Усі файли лежать в одній папці, без підпапок — тому їх можна завантажити на GitHub одним виділенням:
*Add file → Upload files* → виділіть **усі** файли (Ctrl+A) → *Commit changes*.

Файл `.nojekyll` прихований — якщо він не вибирається, це не страшно (для Vercel він не потрібен).

- **Vercel:** підключіть репозиторій, Framework Preset — *Other*, без команди збірки. Кожен коміт оновлює сайт автоматично.
- **GitHub Pages:** *Settings → Pages* → Deploy from a branch → `main` / `(root)`.

## Налаштування

- **Кольори** — змінні на початку `style.css` (`--lilac`, `--solid`, `--sailing`, `--dive`, `--deep`, `--night`).
- **Поля форм і тексти промптів** — `app.js`: об'єкт `CONFIGS` і функції `build…`.
- **Хвиля на фоні** — `wave.webp`.
